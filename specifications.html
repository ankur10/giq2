Desktop reading views keep the list and selected item together. Below 768px, signal choices become a horizontal strip above the reader, and navigation becomes a drawer.

Implementation handoff

The original GrowthIQ application repository and API contracts were not provided. This package is a self-contained HTML/CSS/JavaScript prototype. Apply these components to the production frontend while preserving existing endpoint shapes, permissions, pagination, authentication and generation flows.

Do not present local captured-data search as server-wide search. Client-side comparisons operate on available records. Save/read behavior is local in this prototype; production persistence must use an existing supported service. A missing source stays unavailable until the existing API supplies its destination.
